# Markdown

### Ventanas de Alerta y Estado (Callouts)

Sintaxis para copiar:
```text
> [!NOTE]
> Nota: Úsalo para añadir aclaraciones informativas comunes.
```
Resultado visual:
> [!NOTE]
> Nota: Úsalo para añadir aclaraciones informativas comunes.

---

Sintaxis para copiar:
```text
> [!TIP]
> Consejo: Ideal para trucos rápidos, recomendaciones o atajos de teclado.
```
Resultado visual:
> [!TIP]
> Consejo: Ideal para trucos rápidos, recomendaciones o atajos de teclado.

---

Sintaxis para copiar:
```text
> [!IMPORTANT]
> Importante: Resalta información crucial que no debe pasarse por alto.
```
Resultado visual:
> [!IMPORTANT]
> Importante: Resalta información crucial que no debe pasarse por alto.

---

Sintaxis para copiar:
```text
> [!WARNING]
> Advertencia / Aviso: Úsalo para advertir sobre posibles fallos o configuraciones peligrosas.
```
Resultado visual:
> [!WARNING]
> Advertencia / Aviso: Úsalo para advertir sobre posibles fallos o configuraciones peligrosas.

---

Sintaxis para copiar:
```text
> [!CAUTION]
> Peligro: Para alertas críticas (por ejemplo: "¡Este comando borra la base de datos!").
```
Resultado visual:
> [!CAUTION]
> Peligro: Para alertas críticas (por ejemplo: "¡Este comando borra la base de datos!").

---

### Callouts Avanzados de Obsidian

Sintaxis para copiar:
```text
> [!INFO]
> Información: Datos de referencia técnica o aclaraciones generales.
```
Resultado visual:
> [!INFO]
> Información: Datos de referencia técnica o aclaraciones generales.

---

Sintaxis para copiar:
```text
> [!TODO]
> Tareas pendientes: Puedes incluir casillas de verificación aquí dentro.
> - [ ] Tarea por hacer.
```
Resultado visual:
> [!TODO]
> Tareas pendientes: Puedes incluir casillas de verificación aquí dentro.
> - [ ] Tarea por hacer.

---

Sintaxis para copiar:
```text
> [!EXAMPLE]
> Ejemplo: Úsalo para mostrar casos prácticos de uso de un script.
```
Resultado visual:
> [!EXAMPLE]
> Ejemplo: Úsalo para mostrar casos prácticos de uso de un script.

---

Sintaxis para copiar:
```text
> [!SUCCESS]
> Éxito / Resuelto: Excelente para registrar cuando un proceso terminó correctamente.
```
Resultado visual:
> [!SUCCESS]
> Éxito / Resuelto: Excelente para registrar cuando un proceso terminó correctamente.

---

Sintaxis para copiar:
```text
> [!FAILURE]
> Fallo / Error: Para registrar logs de error o comandos que fallaron.
```
Resultado visual:
> [!FAILURE]
> Fallo / Error: Para registrar logs de error o comandos que fallaron.

---

### Callouts Plegables (Interactivos)

Sintaxis para copiar (Desplegado por defecto, el signo + permite contraerlo):
```text
> [!TIP]+ Haz clic aquí para contraer o desplegar el contenido
> Contenido oculto o secundario de tu guía.
```
Resultado visual:
> [!TIP]+ Haz clic aquí para contraer o desplegar el contenido
> Contenido oculto o secundario de tu guía.

---

### Bloques de Código con Resaltado de Sintaxis

Sintaxis para copiar (Script en Bash / Linux):
```text
```bash
#!/bin/bash
echo "Ejecutando..."
```
```

Sintaxis para copiar (Script de Windows - CMD / Batch):
```text
```cmd
@echo off
echo Ejecutando...
```
```
